## 4. 验收项

> 所有命令的 `workdir` 为 `app/`（除 S2.1 文件检查在仓库根）。证据保存到 `Stage2 - Flutter骨架与领域基础/验收证据/`。

### S2.1 关键文件存在性（自动化）

- **目的**：3 个 SubStage 产出文件齐全。
- **操作步骤**（PowerShell，仓库根执行）：
  ```powershell
  $files = @(
    "app\pubspec.yaml","app\analysis_options.yaml","app\lib\main.dart","app\lib\app.dart",
    "app\lib\di\providers.dart","app\tool\check_layering.dart",
    "app\lib\domain\models\dk_score.dart","app\lib\domain\models\app_config.dart",
    "app\lib\domain\exceptions\dk_exception.dart",
    "app\lib\domain\ports\midi_input_port.dart","app\lib\domain\ports\file_system_port.dart",
    "app\lib\domain\ports\config_repository_port.dart",
    "app\test\domain\models\dk_score_test.dart","app\test\domain\models\app_config_test.dart",
    "app\test\domain\exceptions\dk_exception_test.dart"
  )
  foreach ($f in $files) { if (Test-Path -LiteralPath $f) { "OK: $f" } else { "FAIL: $f" } }
  ```
- **期望结果**：15 行全部 "OK:"。
- **通过标准**：无 "FAIL:"。
- **失败标准**：任一 "FAIL:"。
- **证据要求**：stdout 保存到 `验收证据/S2.1.log`。

---

### S2.2 依赖解析（自动化）

- **目的**：pubspec 依赖可解析，无音频/网络违规包。
- **操作步骤**（workdir=`app`）：
  ```
  flutter pub get
  ```
  然后检查 `pubspec.yaml` 不含黑名单包：
  ```powershell
  Select-String -Path app\pubspec.yaml -Pattern "audioplayers|just_audio|soundfont|^\s*http:|^\s*dio:" 
  ```
- **期望结果**：`flutter pub get` 以 `Got dependencies` 结束（exit 0）；黑名单检索无输出。
- **通过标准**：pub get exit 0 且黑名单检索为空。
- **失败标准**：pub get 失败或检索到黑名单包。
- **证据要求**：stdout 保存到 `验收证据/S2.2.log`。

---

### S2.3 静态分析 0 警告（自动化）

- **目的**：代码符合 lint，无任何 analyzer 问题。
- **操作步骤**（workdir=`app`）：
  ```
  flutter analyze
  ```
- **期望结果**：输出 `No issues found!`。
- **通过标准**：exit 0 且无 error/warning/info（`No issues found!`）。
- **失败标准**：出现任一 error 或 warning。
- **证据要求**：stdout 保存到 `验收证据/S2.3.log`。

---

### S2.4 单元测试全绿（自动化）

- **目的**：领域层模型/配置/异常行为正确。
- **操作步骤**（workdir=`app`）：
  ```
  flutter test
  ```
- **期望结果**：所有测试通过，输出 `All tests passed!`。
- **通过标准**：exit 0 且 `All tests passed!`，且包含设计文档列出的测试（DkScore T1-T7、AppConfig C1-C6、Exception E1-E2）。
- **失败标准**：任一测试失败或缺失关键用例。
- **证据要求**：stdout 保存到 `验收证据/S2.4.log`。

---

### S2.5 分层约束自检（自动化，强约束）

- **目的**：领域层零平台依赖（Version 设计文档 2.2 / 禁止事项 F-01）。
- **操作步骤**（workdir=`app`）：
  ```
  dart run tool/check_layering.dart
  ```
- **期望结果**：输出以 `LAYERING OK: scanned` 开头，exit 0。
- **通过标准**：exit 0 且无 `LAYERING VIOLATION`。
- **失败标准**：出现任一 `LAYERING VIOLATION` 或脚本 exit 非 0。
- **证据要求**：stdout 保存到 `验收证据/S2.5.log`。

---

### S2.6 DK 谱 JSON 字段契约抽检（人工 + 自动化辅助）

- **目的**：DK 谱 JSON 顶层字段名严格符合 Version 设计文档 3.1（防止 F-06 违规）。
- **操作步骤**（workdir=`app`）：运行一个临时断言或检查 `dk_score_test.dart` 中 T2 用例存在并通过：
  ```powershell
  Select-String -Path app\test\domain\models\dk_score_test.dart -Pattern "dkVersion|tempoMap|sourceMidiSha256|totalDurationMs"
  ```
- **期望结果**：检索到 T2 字段名断言相关内容；S2.4 中该测试通过。
- **通过标准**：字段名断言存在且测试通过。
- **失败标准**：缺少字段名契约断言。
- **证据要求**：stdout 保存到 `验收证据/S2.6.log`。

## 5. 失败与阻塞处理

| 场景 | 处理 |
|---|---|
| S2.1 文件缺失 | 回退对应 SubStage 补齐文件 |
| S2.2 pub get 失败 | 检查网络/版本约束；调整 pubspec 后重试，最多 3 次 |
| S2.2 检索到黑名单包 | 回退移除该依赖（违反 F-02/F-03） |
| S2.3 有 warning | 回退对应 SubStage 修复（禁止豁免） |
| S2.4 测试失败 | 定位到对应 SubStage 修复实现或测试 |
| S2.5 分层违规 | 回退对应 SubStage 移除违规 import |
| 网络不可达导致 pub get 失败 | 标记"阻塞"，记录原因，不得标记 Stage 完成 |
