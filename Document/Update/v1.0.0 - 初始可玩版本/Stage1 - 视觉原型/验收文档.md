## 1. 验收范围

### 1.1 覆盖

| 项 | 形式 |
|---|---|
| 4 个 SubStage 产出文件完整性 | 自动化 `find` |
| HTML 文件可在浏览器打开无报错 | 人工浏览器打开 |
| Tailwind CSS 通过 CDN 正确加载 | 人工目检（无 Tailwind 时页面会"裸"） |
| 每个子页面的状态切换、交互可工作 | 人工逐项点击 |
| 播放器页的循环下落动画明显工作 | 人工观察 |
| 屏幕容器固定 1200×540 | 人工 DevTools 检查 |
| 元素清单覆盖度 | 人工对照设计文档清单 |
| 用户对视觉与交互整体满意 | **用户人工确认（强门禁）** |

### 1.2 不覆盖

| 项 | 原因 |
|---|---|
| 颜色精确 RGB | 设计文档允许使用 Tailwind 抽象类 |
| 字体精确 | 系统默认即可 |
| 跨浏览器一致性 | 仅 Chromium 系 + Firefox 120+ |
| 动画 60fps 性能 | 原型阶段不要求 |
| Flutter 代码 | Stage 2+ |
| iframe 在 file:// 下的所有浏览器兼容 | README 已说明备选方案（本地 http.server） |

## 4. 验收项

### V1.1 产出文件存在性（自动化）

- **目的**：4 个 SubStage 全部交付。
- **操作步骤**：在 `Stage1 - 视觉原型/prototype/` 目录执行
  ```bash
  cd "Document/Update/v1.0.0 - 初始可玩版本/Stage1 - 视觉原型/prototype"
  for f in index.html user_flow.md README.md shared/styles.css \
           pages/library.html pages/settings.html pages/convert.html pages/player.html; do
    test -s "$f" && echo "OK: $f" || echo "FAIL: $f"
  done
  ```
- **期望结果**：8 行 "OK:" 输出
- **通过标准**：8 行全为 "OK:"
- **失败标准**：任一为 "FAIL:"
- **证据要求**：完整 stdout 保存到 `验收证据/V1.1.log`

### V1.2 HTML 静态合规性（自动化辅助）

### V1.3 浏览器打开无报错（人工）

- **目的**：HTML 可被浏览器正常解析、Tailwind CDN 加载成功、无 console 报错。
- **操作步骤**：
  1. 在 `prototype/` 目录起本地服务器：`python -m http.server 8000`
  2. 浏览器打开 `http://localhost:8000/index.html`
  3. 打开 DevTools Console，观察是否有 ERROR 级别消息（WARNING 级别可忽略）
  4. 依次切换顶部 4 个 tab，观察 iframe 是否成功加载子页
  5. 单独打开 `http://localhost:8000/pages/library.html` 等 4 个子页，分别检查 console
- **期望结果**：
  - 主入口 + 4 个子页 console 均无 ERROR
  - Tailwind 样式生效（可通过"页面是否裸样式"目测）
  - iframe 内子页正确加载且尺寸固定
- **通过标准**：以上 3 条全部满足
- **失败标准**：任一页 console 有 ERROR / Tailwind 未加载 / iframe 加载失败
- **证据要求**：console 截图 1 张（主入口）+ 文字说明
- **证据保存**：`验收证据/V1.3.png` 或 `.md`

## 5. 失败与阻塞处理

| 场景 | 处理 |
|---|---|
| V1.1 / V1.2 失败 | 直接回退对应 SubStage，禁止豁免 |
| V1.3 浏览器有 ERROR | 回退对应 SubStage 修复，禁止豁免 |

| V1.7 流程图不足 | 回退 SubStage 1.4 补充 |

| Tailwind CDN 网络不可达 | 已知问题，README 提供本地 Tailwind 文件方案；属技术风险非验收失败 |
