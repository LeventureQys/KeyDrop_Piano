## 1. 集成测试

**场景 1：学习模式 - 按对全部 note**
- 加载 fixture f0_cmajor_scale 的 DkScore
- 启动播放器（学习模式）
- 循环注入 8 组 noteOn (pitch 60~72, 间隔 500ms)
- 断言：phase = finished, stats.perfect = 8, stats.miss = 0

**场景 2：演奏模式 - 掉 key**
- 同上，但不注入 MIDI，让时间推进
- 断言：phase = finished, stats.miss >= 1

**场景 3：学习模式结束后返回库**
- 模拟演奏完成→tap 返回库→断言看到库页面

## 2. 真机验收指南
逐项操作清单，用户自行执行并反馈结果。覆盖：
- OTG 连接电钢琴 → App 显示设备名
- 导入 MIDI → 生成 DK 谱 → 保存
- 学习模式弹奏 → 按对/按错反馈
- 演奏模式弹奏 → 统计正确
- 设置修改 → 重启 App 保持
