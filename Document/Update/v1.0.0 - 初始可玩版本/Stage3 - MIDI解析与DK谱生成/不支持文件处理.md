# Stage 3 - 不支持 / 损坏 MIDI 文件处理清单（SubStage 3.3）

> 本清单定义 `MidiParser` 在遇到不支持或损坏文件时抛出的异常类型及对应 **UI 弹窗文案**，供 Stage 5 转换页（原型 `convert.html` 的异常状态 CVT-E）直接使用。UI 层捕获任一 `DkException` 后弹 AlertDialog 显示文案，不崩溃。

## 触发条件 → 异常 → UI 文案

| 编号 | 触发条件 | 抛出异常 | UI 文案 | 解析器位置 |
|---|---|---|---|---|
| U1 | SMF 格式 2 | `UnsupportedMidiFormatException` | 此文件为 SMF 格式 2，v1.0.0 仅支持格式 0/1。 | `midi_parser.dart` 头部 `format == 2` |
| U2 | SMPTE 时基（division 最高位=1） | `UnsupportedMidiFormatException` | 此文件使用 SMPTE 时基，暂不支持。 | 头部 `division & 0x8000` |
| U3 | 未知 SMF 格式（非 0/1/2） | `UnsupportedMidiFormatException` | 未知的 SMF 格式 (N)。 | 头部 `format != 0 && != 1` |
| U4 | 无任何可演奏音符 | `UnsupportedMidiFormatException` | 未在文件中找到可演奏的音符。 | 解析末尾 `notes.isEmpty` |
| C1 | MThd 魔数不匹配 | `CorruptedMidiException` | 文件已损坏：在 chunk header 处读取失败。 | 头部 magic 校验 |
| C2 | MThd 长度字段 ≠ 6 / division ≤ 0 | `CorruptedMidiException` | 文件已损坏：MThd 长度字段异常 / division 字段异常。 | 头部 |
| C3 | MTrk 魔数缺失 | `CorruptedMidiException` | 文件已损坏：音轨 header 缺失 (MTrk)。 | 轨道循环 |
| C4 | 轨道长度越界 / 读取越界 | `CorruptedMidiException` | 文件已损坏：音轨长度越界 / 读取越界。 | `_Reader` 越界检查 |
| C5 | running status 缺失 | `CorruptedMidiException` | 文件已损坏：running status 缺失。 | 事件循环 |
| C6 | VLQ 过长 / 未知事件状态 | `CorruptedMidiException` | 文件已损坏：可变长度量过长 / 未知事件状态。 | `_Reader.readVlq` / 事件循环 |
