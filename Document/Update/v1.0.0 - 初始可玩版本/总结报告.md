## 0. 发现的主要范式偏差与修复

| 偏差 | 文档依据 | v1.0.1 修复 |
|---|---|---|
| 生产 DI 装配了 `InMemoryFileSystemPort.withSampleData()` 与裸 `DebugMidiInjector`（假数据、无真实输入） | Stage 4.3 / Stage 5 §2 | 平台判定装配：Android → 真实适配器；debug 构建注入器**装饰**真实适配器（R4/R5） |
| `MidiInputPlugin.kt` 打开了 input port 但**未 `connect(MidiReceiver)`**，`handleMidiData` 是死代码 | Stage 4.1 / C1 | 接入 `onSend` 回调 → 11 字节包 → EventChannel；设备插拔自动连接；错误映射 `MidiDeviceConnectionException` |
| 转换流程断链：`pickMidiFile` 拿到路径后什么都不做，没有任何代码读取/解析所选文件 | Stage 5 §4.3 | `pick → readMidiFile（平台层读字节）→ sha256 → compute isolate 解析 → 选轨 → 预览 → 保存` 全链路（R1/F-05） |
| 判定引擎未按公式 `按下 - (触底 + latencyOffset)`，latencyOffset 未生效；和弦同 t 键会被吞 | Version 3.2 / F4 | 公式修正 + `(t, pitch)` 唯一身份 + 和弦独立判定（R2/R3） |
| 学习模式无"卡住等待"语义、错音无红框脉冲与键位红高亮 | F1 | 时间线吸附判定线冻结 + 等待呼吸动画 + 红框脉冲 300ms + 错键红 0.5s / 对键绿 200ms |
| 信息栏缺 BPM/拍号/调号/小节/设备状态；无模式选择与播放器内切换 | E4 / V7 / V8 | 信息栏全项 + 库页模式选择对话框 + 播放器内模式切换 |
| 播放器固定 1200×540 画布、键盘硬编码 32 键、滚动模式未实现 | E1/E2/E3 | 响应式三段布局（15%/65%/20%）+ viewportKeys 自适应 + auto/manual/fixed 滚动 |
| 库页"导入 DK 谱"是空操作、"导出"未接线、无 DkException 弹窗 | V9 / T8 / 3.5 | SAF 导入 DK 谱（端口新增 `importDkScore`）+ 导出接线 + 统一错误弹窗 |
| 设置"校准"为 3 秒假对话框 | C3 | 真实测量：事件到达时刻 − 平台时间戳 → `inputLatencyOffsetMs`（R7） |
| `integration_test/` 缺失、fixture 与 golden 谱缺失、`scripts/check_layering.sh` 缺失 | V3 / 2.3 / V1 | 5 场景集成测试 + 验收命名 fixtures + golden + bash 脚本（R11/R12） |
| 判定/统计/BPM 逻辑散落在 UI 层控制器 | Version 2.1 | 收敛为领域服务 `JudgmentEngine` / `StatisticsAggregator` / `BpmScaler`（R13） |
| `main.dart` 横屏 TODO、无屏幕常亮、Manifest 未锁横屏 | Version 决策表 | `SystemChrome` + Manifest `screenOrientation` + `keydrop_piano/lifecycle` 通道控制 `FLAG_KEEP_SCREEN_ON` |
