## 2. 验收项

### S6-1. 信息栏全项（E4 + Stage 6 4.5）
- **操作**：`flutter test test/ui/player_page_test.dart --plain-name '播放器信息栏展示曲名/BPM/拍号/调号/模式/设备状态'`。
- **期望**：曲名、BPM、拍号、调号、模式标签、设备状态（连接/未连接）全部渲染。

### S6-2. 学习模式判定与反馈（F1）
- **操作**：同文件 `--plain-name '学习模式：按错音红色反馈并等待，按对后继续，结束显示结算'`。
- **期望**：按错音 → 错音计数 + 仍卡住等待；按对 → 继续；全部判定 → 结算页显示综合得分与五项明细。

### S6-3. 暂停遮罩（真机指南 T7）
- **操作**：同文件 `--plain-name '暂停遮罩：继续 / 重新开始 / 退出'`。
- **期望**：遮罩含 继续/重新开始/退出；继续后恢复播放。

### S6-4. 判定引擎单元（F2/F4/3.2 公式）
- **操作**：`flutter test test/domain/services/judgment_engine_test.dart`。
- **期望**：窗口三档数值、`delta = 按下 - (触底 + offset)` 公式、和弦同 t 不同 pitch
  独立判定、学习模式到期无上限/过早不吞 note、计分公式（100/70/70/0/0）。

### S6-5. BPM 倍率时间线（需求 6 / V3-E）
- **操作**：`flutter test test/domain/services/bpm_scaler_test.dart`。
- **期望**：2.0x 时播放时间线 = 实际经过 × 2（事件时刻 = 原 t × 0.5，误差 ≤ 1ms）。

### S6-6. 静态质量
- **操作**：`flutter analyze`。
- **期望**：`No issues found!`。
