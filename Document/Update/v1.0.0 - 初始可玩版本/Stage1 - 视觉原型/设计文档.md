## 1. Stage 目标与背景

### 1.1 目标（1 句话）

产出 v1.0.0 全部 4 个核心页面的**可在浏览器中打开、具备简单交互的 HTML 原型**（Tailwind CDN + 原生 JS，单 `index.html` 多页路由，含循环下落动画），供用户视觉与交互双重确认后冻结 UI 决策。

### 1.2 背景

- v1.0.0 是 KeyDrop_Piano 项目首个 Version，仓库无任何代码。
- 直接进入 Flutter 代码开发 UI，若用户对布局/交互不满意会大量返工。
- HTML 原型阶段可以让用户**真正点击、看到下落动画节奏感**，比静态截图发现更多体验问题。
- 原型代码丢弃即可，不影响 Flutter 主代码库。

### 1.3 产出形式（强制）

#### 1.3.1 目录结构

所有产物位于 `Stage1 - 视觉原型/prototype/`：

```
prototype/
├── README.md                       # SubStage 1.4 产出：使用说明（如何打开、需联网拉 CDN 等）
├── index.html                      # SubStage 1.4 产出：主入口，hash 路由 + iframe 嵌入子页
├── pages/
│   ├── library.html                # SubStage 1.1：谱面库页（含两种状态）
│   ├── settings.html               # SubStage 1.1：设置页
│   ├── convert.html                # SubStage 1.2：谱面转换页（4 状态 + 异常弹窗）
```

#### 1.3.2 技术栈约束（强制）

| 项 | 规则 |
|---|---|
| CSS 框架 | **Tailwind CSS via CDN**：`<script src="https://cdn.tailwindcss.com"></script>` |
| JS 框架 | **无**。仅原生 ES2020+ JS，写在 `<script>` 标签内或独立 `.js` 文件 |
| 构建步骤 | **无**。所有 .html 文件浏览器双击即可打开（联网状态下） |
| 字体 | 系统默认（`system-ui`）+ 备选 `sans-serif`；不外引字体文件 |
| 图标 | 使用 Unicode 字符或内嵌 SVG（不引图标库） |
| 浏览器目标 | Chromium 120+ / Edge 120+ / Firefox 120+ |

#### 1.3.3 屏幕模拟约束（强制）

**所有页面必须模拟横屏 2400×1080 手机屏幕**。具体实现方式：

- 在 `<body>` 内放一个 `<div class="screen">` 作为屏幕容器
- 容器固定 CSS：`width: 1200px; height: 540px;` （= 真机尺寸 1/2 缩放，便于桌面浏览器查看）
- 容器内部所有元素按 1200×540 的视口设计
- 子页面（被 iframe 嵌入时）也必须遵守此尺寸：`<html>` / `<body>` 设置 `overflow: hidden`，根容器固定 1200×540
- 信息栏高度 ≤ 540 × 15% = 81px
- 键盘高度 ≈ 540 × 20% = 108px
- 下落区高度 = 540 - 信息栏 - 键盘 ≈ 351px
- 单白键宽度 = 1200 / 32 ≈ 37.5px → **取整 37px**，最后一键溢出由 max-width 处理
- 黑键宽度 = 37 × 0.6 ≈ 22px

> **像素换算口诀**：原型像素 × 2 = 真机像素（横屏 2400×1080 ↔ 原型 1200×540）

#### 1.3.4 命名约定

| 类型 | 命名 | 示例 |
|---|---|---|
| HTML 文件 | 小写蛇形 | `page_library.html` ❌ → 用 `library.html` ✅（已确定文件名见 1.3.1） |
| ID | 小写连字符 + 页面前缀 | `library-list`、`settings-bpm-slider` |
| CSS class | Tailwind 优先；自定义类用 BEM `block__element--modifier` | `key__white--active` |
| JS 函数 | 小驼峰 | `showLibraryEmpty()` |
| 数据属性 | `data-` 前缀 + 蛇形 | `data-page="library"`、`data-mode="learning"` |

#### 1.3.5 适用约束（来自 Version 决策）

| 约束 | 来源 | 在原型中如何体现 |
|---|---|---|
| 屏幕方向 | E2 | 屏幕容器固定 `1200×540`，超出范围内容不出现滚动 |
| 安全区 | E2 | 屏幕容器内左右 padding ≥ 20px |
| 键盘默认 | E1 | 32 键视口，88 键概念可通过滚动条左右滚动 |
| 信息栏 | E4 | 包含曲名/BPM/拍号/调号/小节/进度/模式/统计 |
| 下落 | E3 | 屏高 / 1.5 秒 → 原型像素 351 / 1.5 ≈ 234 px/s（循环演示用此速度） |
| 学习反馈 | F1 | 错音 → 整屏 0.3s 红色脉冲边框 + 错键位红色高亮 0.5s |
| 演奏统计 | F2 | 信息栏右侧实时显示"完美/抢/拖/掉/错"五项数字（原型用 0/0/0/0/0 起始） |
| 暂停 | 设计自决 | 信息栏右上角有暂停按钮 |

### 3.3 SubStage 1.3 - 播放器原型

#### 背景与目标

- **背景**：v1.0.0 最复杂的一页，需同时承载学习/演奏双模式 + 信息栏 + 下落区 + 键盘 + 错音反馈 + 结算页 + **循环下落动画演示**。
- **目标**：产出含 5 个状态 + 循环下落动画 + 关键尺寸正确的 HTML 播放器页。

#### 输入

- 本设计文档 + [Version 设计文档第 3.2 节](../设计文档.md) + 问题清单 C3/E1/E3/E4/F1/F2 答复

#### 屏幕布局（必须严格遵守像素）

```
1200px 宽 × 540px 高
┌───────────────────────────────────────────────────────────┐ ← y=0
│ 信息栏（高 81px / ≤ 15%）                                 │
│ [曲名+作曲家] [BPM] [拍号] [调号] [小节] [进度条] [模式] [统计] [⏸] [返回] │
├───────────────────────────────────────────────────────────┤ ← y=81
│                                                           │
│ 下落区（高 351px / ≈ 65%）                                 │
│   ↓ key 从顶部下落 ↓                                       │
│                                                           │
│   循环动画：8 拍 mock 数据，下落速 234 px/s                │
│                                                           │
│                                                           │
│ ━━━━━━━━━━━━━ 判定线 ━━━━━━━━━━━━━━━━━━━━━━━━━ │ ← y=432（判定线就是键盘顶部）
├───────────────────────────────────────────────────────────┤ ← y=432
│ 键盘区（高 108px / ≈ 20%）                                 │
│ 32 键白键宽 37px、黑键宽 22px、黑键高 60%                  │
└───────────────────────────────────────────────────────────┘ ← y=540
```

#### 必须实现的 5 状态

通过页面右上角的状态切换栏（原型调试用）在以下状态间切换：

1. **学习模式 - 等待按键**
   - 默认状态
   - 至少一个 key 已"触底"停在键面上方等待
   - 信息栏模式标签显示"学习模式"
   - 下方继续有 key 持续下落（循环动画）
2. **学习模式 - 用户按错**
   - 整屏 0.3 秒红色边框脉冲动画
   - 错按的键位高亮红色 0.5 秒
   - 触发方式：原型用按钮"模拟按错"触发
3. **演奏模式 - 时间线推进**
   - 切到演奏模式，key 不再停止，按节奏循环下落
   - 信息栏右侧统计数字（完美/抢/拖/掉/错）每个 key 触底时随机递增
4. **暂停遮罩**
   - 半透明黑色覆盖层 + 居中三个按钮"继续 / 重新开始 / 退出"
5. **结算页**
   - 全屏结算视图
   - 综合得分（大数字百分比）
   - 五项统计明细
   - 按钮"再来一次" / "返回库"

#### 必须实现的循环下落动画（核心）

- mock 一段 8 拍数据：例如 C 大调音阶 C4 D4 E4 F4 G4 A4 B4 C5（pitch = 60 62 64 65 67 69 71 72，t 间隔 500ms）
- 用 CSS animation 或 `requestAnimationFrame` 让每个 key 从下落区顶部以 **234 px/s** 速度下落到判定线
- 8 拍循环结束后无缝从头开始
- 学习模式下，到达判定线的 key 停止下落，等待下一次循环（原型可简化为：每 4 秒自动跳过等待）
- 演奏模式下，到达判定线的 key 触发"键位短暂高亮 + 触底 ripple 动画"，然后消失

**键位高亮规则**：

- 触底 ripple：从判定线向上扩散的圆形透明渐淡效果，持续 200ms
- 学习模式按对：键位短暂绿色高亮 200ms
- 学习模式按错：键位红色高亮 500ms

#### 必须的交互

1. 状态切换栏（5 按钮）：切换 5 状态
2. 模式切换按钮（信息栏内）：切换学习/演奏
3. "模拟按对" / "模拟按错"按钮（原型调试用）：触发对应反馈
4. 暂停按钮：触发暂停遮罩
