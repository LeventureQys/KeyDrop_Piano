# v1.0.0 真机验收指南

> 用户自行执行，按清单逐项验证。每项勾选通过/失败，记录问题。

## 环境
- 手机：小米 17 Ultra（Android 最新）
- 电钢琴：任一支持 USB MIDI Class Compliant 的型号（如 Yamaha P 系列 / Casio CDP / Roland FP）
- 连接：电钢琴 USB-B → USB-C OTG 转接头/线 → 手机
- APK：`app/build/app/outputs/flutter-apk/app-debug.apk`（需通过 `flutter install` 或直接 adb install 部署）

## 验收清单

### T1. 安装与启动
- [ ] APK 可正常安装到手机
- [ ] 启动 App 后显示谱面库页（空库状态："还没有任何谱面"）

### T2. 设置页
- [ ] 点击齿轮进入设置页
- [ ] 所有控件（收音/滑块/开关）可交互
- [ ] 底部 JSON 预览实时更新
- [ ] 修改设置 → 返回 → 再次进入 → 设置保持
- [ ] 校准按钮可弹出对话框 3 秒后关闭

### T3. 谱面转换
- [ ] 库页点击 FAB "+"→"从 MIDI 文件创建"
- [ ] 选择 MIDI 文件 → 显示轨道列表
- [ ] 选择旋律轨 → 进入预览（显示 BPM/拍号/调号/时长）
- [ ] 编辑曲名/作曲家 → 保存 → 库页刷新显示新条目

### T4. USB MIDI 连接（核心）
- [ ] 插入电钢琴 USB OTG 线
- [ ] App 是否显示已连接设备名（信息栏/设置页状态指示）
- [ ] 拔出电钢琴 → App 显示断开

### T5. 学习模式（连接电钢琴）
- [ ] 库页选择一个谱面 → 进入播放器
- [ ] 模式标签显示"学习"
- [ ] 按下对应键 → 键位绿色高亮 → 进入下一个 note
- [ ] 按错键 → 红色高亮 0.5 秒 → 仍然等待正确键
- [ ] 全部弹完后显示结算页

### T6. 演奏模式
- [ ] 切换至演奏模式
- [ ] Key 持续下落（不等用户）
- [ ] 实时统计更新
- [ ] 结算页显示综合得分（百分比）

### T7. 暂停/恢复
- [ ] 点击暂停 → 遮罩层显示"继续/重新开始/退出"
- [ ] 点击继续 → 恢复演奏

### T8. DK 谱导出
- [ ] 库页长按谱面 → "导出"→ SAF 选择位置 → 导出成功
