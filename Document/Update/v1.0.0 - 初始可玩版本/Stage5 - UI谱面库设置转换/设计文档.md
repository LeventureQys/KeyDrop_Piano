## 2. Provider 架构
- `configRepositoryProvider` → `AndroidConfigRepository()`（生产）或 mock
- `fileSystemProvider` → `InMemoryFileSystemPort()`（开发）/ `AndroidFileSystemAdapter()`（生产）
- `appConfigProvider` → `StateNotifierProvider<AppConfigNotifier, AppConfig>`（load→save 双向）
- `scoreListProvider` → `FutureProvider.autoDispose<List<DkScoreFile>>`（每次进库页刷新）
- `convertStateProvider` → `StateNotifierProvider<ConvertStateNotifier, ConvertState>`（5 状态）

## 3. 导航
`MaterialApp` 的 `home` 使用 `IndexedStack` + 底部 TabBar（选择方案：顶部 TabBar 三个 tab 同名原型 tabs）。保持索引隐藏？实际 App 流程为：库 → 设置(←←) / 转换(←←)。不适用 TabBar。用 `Navigator.push` / 简单 `_currentPage` 索引切换。
采用：Provider `currentPageIndex`(0=库,1=设置,2=转换,3=播放器预留) + `IndexedStack`。

## 4. 页面实现要点

### 4.1 library_page
- `Consumer` 监听 `scoreListProvider`（异步列表）
- 空列表 → 显示导入引导（emoji + 提示 + "开始导入"按钮）
- 有列表 → 搜索框 + 列表项 + FAB
- 搜索：`TextEditingController` + `filteredScores = scores.where(...)`（前缀匹配）
- FAB 展开：两个 ActionChip + AnimationController
- 长按：`GestureDetector.onLongPressStart` → `showMenu` 或自定义 overlay

### 4.2 settings_page
- `Consumer` 监听 `appConfigProvider`
- 5 组卡片（键盘/显示/判定/演奏/调试）
- 控件变化 → `provider.setHardwareKeyboardKeys(...)` 等
- 底部 JSON 预览实时反映 `AppConfig.toJson()`
- 校准按钮：`showDialog` 3 秒自动关闭 → 设 latency=18

### 4.3 convert_page
- `Consumer` 监听 `convertStateProvider`
- State A → 大按钮"选择 MIDI 文件"→ 调用 `fileSystemProvider.pickMidiFile()` → 解析
- 解析：`MidiParser().parse(bytes)` → `MidiData`
- State B → 轨道列表 + 单选 → 选轨后启用"下一步"
- State C → 曲名/作曲家编辑 + meta 卡片 + "下一步"
- State D → 文件名输入 + `DkGenerator().generate()` + `writeDkScore()`
- State E → 异常弹窗（解析失败时触发）
